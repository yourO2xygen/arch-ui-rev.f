# Research digest: подходы к дизайну в духе ARCH·UI (для ревизии REV.E)

Собрано 2026-11-05 из веб-поиска и статей (NN/g, Sara Soueidan, Setproduct, HN, трендовые
обзоры). Задача — применить к макету design-proposal-2026-11-05.html (сейчас REV.D).

## 1. Референсы эстетики (что используют похожие дизайны)

- **Bloomberg Terminal** (HN-обсуждение, 2019; bloomberg.com/company/stories — за капчей):
  эталон info-dense интерфейса: «High contrast, monospaced fonts, extensive keybindings».
  Приёмы: жёсткие функциональные цвета по типам данных при общем ч/б каркасе; панели
  разделены волосяными линиями, не карточками; каждая ячейка подписана кодом-меткой.
- **TUI / terminal-эстетика в вебе** (тренд 2025–26 по обзорам Smashing/Webflow):
  рамки из box-drawing-символов (single/double line), мигающий блок-курсор, ASCII-шкалы,
  статус-строки с инверсными сегментами при нулевом хроме вокруг.
- **CRT / oscilloscope / test-equipment вайб** (Tektronix, HP, ricing-комьюнити):
  сетка-гратage как фон данных (не декор), фосфорные запаздывающие следы при движении
  значений, тумблеры и «аппаратные» переключатели вместо soft-цветных чипов.
- **Modular synth / Teenage Engineering / VCV Rack**: механическая метафора — контролы
  выглядят как физические элементы прибора: тумблер с позицией, радио-кнопка с «утопленным»
  состоянием, счётчики-значения println-весом; аннотации-силкскрины на панели (мелкий
  технический текст на самой панели, как на печатной плате).
- **E-paper UI** (ACM 2026, монозвукристые интерфейсы без цвета): state показывают ВЕСОМ
  (bold/regular), ЗАЛИВКОЙ, инверсией и ГЕОМЕТРИЕЙ, но не цветом; обязательны дублирующие
  текстовые дескрипторы on/off; анимации без полупрозрачностей — резкие смены состояний.

## 2. Конкретика по контролам (из NN/g «Toggle-Switch Guidelines», Sara Soueidan
   «On Designing and Building Toggle Switches», Setproduct «Toggle switch UI design»)

### Тумблер (у нас — DND в notifcenter)
- Анатомия: track + thumb + label; подразумевает НЕМЕДЛЕННЫЙ эффект, не «применить потом».
- Состояние должно читаться без цвета: ПОЗИЦИЯ thumb обязана меняться (физическая метафора),
  плюс контраст: у нас инверсия — thumb/track меняются местами чёрное↔белое.
- NN/g явно: state-дескрипторы «off/on» с ДВУХ сторон трека, иначе дескриптор путается с
  label (наш текущий «dnd» слева от тумблера — риска нет, но ON-состояние стоит
  дублировать словом: «dnd ON» или меткой в foot, foot уже это делает).
- Варианты отображения без цвета (Setproduct/NN/g сводка):
  a) инверсный трек (on = белый трек, чёрный thumb);
  b) текстовый тумблер-«кнопка с ложем»: [ OFF ][ ON ] — сегмент-кнопка из двух половин,
     активная половина инвертирована (Bloomberg/терминальный приём);
  c) радио-строка: «● OFF — ON ○» с точкой-индикатором;
  d) физический рычажок (скос + линия оси), позиционные деления внутри трека.
- Анимация: позиция — 120–160ms; НЕ анимировать цвет отдельно от позиции.

### Чекбокс (в макете появятся фильтры? на будущее)
- Без цвета: квадрат-контур → инверсный квадрат с «✕»/заливкой; indeterminate — тире.

### Input / поле поиска (у нас — dock лаунчера)
- Терминальная метафора из TUI-трендов: НЕ рамка-«пилюля», а подчёркнутая строка или
  вдавленная строка на волосяной линии; промпт-символ перед вводом («>» / «/» / «$») —
  даёт понять, куда падает фокус, без подсветки поля.
- Курсор — блок (block caret), можно мигающий — сильный терминальный сигнал.
- Placeholder не серым, а dim + caps/скобки: «[query]».
- Активное поле: строка под полем становится инверсной или удваивается (2px) — «фокус»
  показывается линией, не свечением.

### Индикация значений / шкалы
- ASCII/TUI-шкалы: из символов ▁▂▃ или из сегментов-тиков; активная часть инверсией.
- Счётчики (воркспейс №, %, часы) — tabular-цифры, старшие нули dim (уже принято в REV.D).

## 4. Что из этого применить к ARCH·UI (гипотезы, не догма)
1. DND: перейти от тумблера-бегунка на сегмент-кнопку [ OFF | ON ] или инверсный трек,
   добавить текстовый дескриптор состояния с активной стороны.
2. Поле лаунчера: убрать «пилюлю», сделать терминальную строку с промптом-символом,
   block-caret и линией-фокусом. Placeholder в терминальных скобках.
3. Панели: усилить Bloomberg-приём — метки-коды у каждого блока данных (аннотации
   «silk-screen»), волосяные разделители, инверсные статус-сегменты.
4. Шкалы-бары в sysinfo и ОСД: сегменты-тики с инверсией активной части, с тиками-делениями
   (каждый 10-й выше) — продолжение языка REV.D.
5. Календарная сетка: e-paper-приём — выделение дня инверсией без теней; «сегодня» —
   двойная рамка или crosshair-corner (перекрестие по углам) — фирменный приём из REV.D.
6. Ничего нетрозного состояния: hover — инверсия контура, active — полная инверсия;
   смягчать alpha, не добавлять свечений.
