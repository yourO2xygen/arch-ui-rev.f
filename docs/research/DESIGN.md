# ARCH · UI — концепт рабочего стола

> Текстовое описание идеи и правил для переноса в [Quickshell](https://quickshell.outfoxxed.me).
> Живой макет: `index.html` (превью-пульт слева, `esc` — чистый стол, `#static` — всё сразу).
> Текущая версия макета: **v9 · system**.

---

## 1. Идея

Рабочий стол Arch Linux как **приборная панель из ретро-футуризма** — референс
Pacific Drive HUD: эстетика 80-х/90-х, «модифицированная под научную фантастику
приборка старого автомобиля».

Ключевые ощущения:

- **Чёрный — база.** Панели — просто чёрные прямоугольники поверх обоев.
  Обилие пустого чёрного, никакого «стекла-блюра» в материальном смысле.
- **Только данные и индикаторы.** Никаких украшений: если элемент есть — он несёт
  информацию. Консольная дисциплина: моноширинный шрифт, uppercase-метки,
  каретка-подчёркивание `_` вместо системного курсора.
- **Монохром.** Цвета нет вообще. Состояние передаётся тоном и заполнением:
  залитая точка / тусклая / полая, инверсия для ошибок, жирность для акцентов.
- **Тишина вне фокуса.** Стол пустой. Всё появляется по требованию, плавно,
  и так же плавно уходит. Бар существует секунды. Контент никогда не «выпрыгивает»
  раньше самой панели.

Что это даёт пользователю: рабочий стол как cockpit — информация читается
периферийным зрением, ничего не отвлекает, всё на своих местах по строгой сетке.

## 3. Дизайн-система

Все компоненты собраны из общих правил — это главный переносимый артефакт.

### Токены

| Токен | Значение | Смысл |
|---|---|---|
| `surface` | `#000000` | фон панелей |
| `txt` | `#f4f4f5` | основной текст |
| `txt2` | `#a1a1aa` | вторичный |
| `dim` | `#56565e` | метки, мета |
| `ghost` | `#3f3f46` | отключённое |
| `raise` | `rgba(255,255,255,.05)` | ховер |
| `raise2` | `rgba(255,255,255,.09)` | выбрано / нажато |
| `apple` | `cubic-bezier(.25,.1,.25,1)` | кривая всех движений |

### Шкала отступов

Всё кратно 4: `4 · 8 · 12 · 16 · 20 · 24`. Никаких «красивых» 13 и 17.

### Анатомия панели

```
┌────────────────────────────────────────┐
│ ▸ head 40px   [icon 14 + TITLE 11 caps]│  ← иконка и титул на одной линии
├────────────────────────────────────────┤   (flex center, line-height:1)
│ body  pad 12 | 16 | 16                 │
│   секция: LABEL 9 caps dim             │
│            контент (gap 8)             │
│   …между секциями gap 16               │
├────────────────────────────────────────┤
│ foot 30px   meta слева · meta справа   │
└────────────────────────────────────────┘
```

- Шапка без кнопок и бейджей — только иконка, титул, максимум 1–2 чипа данных справа.
- Подвал — узкая мета-строка (user@host, счётчики, подсказки клавиш действий).

### Примитивы контента

| Примитив | Правило |
|---|---|
| Секция | `.lbl` 9px caps dim → контент `gap 8` |
| Строка (row) | h 28 (варианты 30–34) · pad 8 · gap 10 · hover=raise · выбрано=inset-маркер 2px |
| Значение | 15px white + юнит 9px dim рядом |
| Подпись | 9px dim |
| Тело | 11px txt2 |
| Метка строки | 9px caps dim, фиксированная ширина колонки |
| Кнопка | h 26 единая · primary = белая заливка/чёрный текст |
| Чип | 10px, raise · selected = инверсия |
| Поле | h 34 (чат 40) · фон raise2 · каретка `_` 8×2 |
| Полоса метрики | h 4 · **сегментированная** (штрих 4 / пром. 3) · белая |
| Точка состояния | 7px: залитая=работает · тусклая=idle · полая=стоп |
| Ошибка | инверсия: белая плашка + чёрный текст |
| Акцент значения | жирный белый (без цвета) |

### Типографика

- **JetBrains Mono** — единственный шрифт всего UI (400/500/600/700).
- **DSEG7-Classic** — семисегментный, только часы в баре (табло приборки).
  Веса: bold. Источник: пакет `dseg` (jsdelivr в макете; для QS — положить ttf рядом).

### Состояния — без цвета

Принцип: **цвет не существует**. Иерархия важности строится тоном:

1. обычный — `txt2`;
2. важнее — `txt` / жирный;
3. максимум — инверсия (белый фон, чёрный текст): ошибки, power-off, «сегодня» в календаре, активные табы/воркспейсы.

## 4. Компоненты

### bar — статус-бар (транзиент)
- Появляется по `super+shift+s` или клавишам `1–6` (переключение воркспейса).
- Контент: воркспейсы 1–6 (активный — инверсия, занятый — raise), раскладка EN, часы DSEG7 + дата.
- **Автоскрытие 2.8s**; ховер удерживает; повторный вызов — рестарт таймера.

### launcher — запуск (2 стадии)
- **Стадия 1**: один док-инпут 550×48 по центру снизу, плейсхолдер `run…`, каретка `_`.
- **Стадия 2** (первый символ или ↑↓): над инпутом вырастает список 550×372.
- Строки: плитка-инициал 24, имя 11.5, категория 9 dim справа; выбранная — inset-маркер.
- Enter — «запуск» (вспышка строки), ↑↓ — навигация с фильтром по подстроке имени.

### sysinfo — сводка системы
- 4 метрики сеткой 2×2 (cpu / memory / gpu / vram): значение 15 + юнит, подпись 9 (модель, °C), сегментированная полоса, у cpu — спарклайн-гистограмма.
- Секция `HARDWARE`: строки battery / network / vpn / bluetooth / usb — метка caps, значение, мета справа.
- Шапка справа: чип uptime. Подвал: user@host · ядро.

### calendar
- Реальный текущий месяц: навигация ‹ ›, сетка 7×6, ячейки 34px.
- Сегодня — инверсия. Дни других месяцев — ghost. Подвал: номер недели.

### notifmgr — центр уведомлений
- Шапка справа: тумблер DND + Clear.
- Секции `TODAY` / `YESTERDAY`: строки с иконкой-плиткой 24, заголовок 10.5, тело 9.5, время справа; вчерашние — opacity .4.
- DND включён: список приглушается (.3), статус в подвале `dnd on`.

### logout — сессия
- 5 плиток равной ширины: lock / sleep / exit / reboot / power, h 56, иконка + caps-метка.
- Ховер — raise; **power** — ховер инверсией (максимум серьёзности).
- Клик → полноэкранный fade `system halted`-подобной сцены (1.5s) — просто обозначение действия.
- Подвал: user · uptime.

### docker — контейнеры
- Тулбар: имя контейнера 12 600 + чип состояния + 4 иконочки (start/stop/restart/attach) h 26.
- Слева список контейнеров 168px (точка состояния, имя, образ, порт справа) с разделителем 1px.
- Справа табы Logs / Resources / Ports:
  - Logs — терминальный блок 10px/1.7: время dim, источник txt2, warn — жирный, **error — инверсия**;
  - Resources — 4 строки «метка значение + сегм. полоса» + health;
  - Ports — строки маппинга и сети.
- Подвал: `5 running · 1 exited` · версия docker.

### taskmgr — процессы
- Строка: фильтр-поле 34 + чип сортировки.
- Таблица: pid / name / cpu% / mem / user / kill. Ячейки h 30, hover raise, выбранная — inset.
- **Hot-значения CPU — жирный белый** (≥20%). Kill-кнопка появляется на hover, ховер — инверсия; клик — строка гаснет и удаляется.
- Подвал: `10 / 142 · sorted by cpu` · `del · term`.

### chat — диалог с агентом
- Шапка справа: чип модели (инверсия), чип треда, `+`.
- Лента: user — белые пузыри/чёрный текст; бот — raise2; вызов команды — строка `▸ cmd` на raise; карточка «agent question» с кнопками формата ответа (первая — primary).
- Индикатор набора — 3 пульсирующих точки.
- Поле 40 с кареткой `_` и кнопкой-стрелкой; Enter/клик — отправка, ответ через 1.1s (макет).

### aimgr — менеджер агентов
- Табы Active / History (активный — инверсия).
- Секция `RUNNING`: строки с точкой состояния (залита/тусклая), имя 11, модель · токены/с, время справа.
- Секция `MODELS`: радио-строки, выбранная — белый + залитое радио, теги default/local.
- Низ: две равные кнопки New / Kill.

### notifs — тосты
- Стек от y264, ширина 276, gap 8.
- Карточка: иконка-плитка 32, заголовок 11.5, тело 10, время 9 dim, крестик на hover.
- Появление — общий с панелями профиль (fade+scale + ghost-эхо), закрытие — сжатие к .95.

## 5. Движение и эффекты

### Открытие/закрытие (главный ритм)
1. Панель: `opacity 0→1` + `scale .97→1`, **420ms**, кривая apple (`.25,.1,.25,1`) — мягкое проявление на месте, без направления и без bounce.
2. Контент: **появляется только после открытия** — одним куском, fade 220ms на 430-й мс. Пока едет прямоугольник — он пуст.
3. Закрытие — зеркало.

Правило «контент после панели» — фирменное: панель сначала «материализуется»,
потом оживает данные. В QS: `Behavior on opacity/scale` + `Timer(430ms)` на
`contentOpacity`.

### ghost-эхо (открытие)
Два контурных прямоугольника (1px, белый), стартуя с панели, сжимаются внутрь
(`scale .99→.952`) и гаснут (`.45→0`), задержки +40мс/+140мс. Дешёвый «шлейф
материализации». Только на открытие.

### стекло над компонентом
Над каждой панелью — невидимый слой-«стекло»:
- **отражение**: перевёрнутая (`scaleY(-1)`) копия контента, `blur 3px`,
  `mix-blend screen` (чёрный исчезает — отражается только светлое), opacity ~.14,
  маска-затухание к 24% высоты; в макете — статичный клон, **в QS заменить на живой
  `ShaderEffectSource`**;
- спекулярный блик — диагональная белая полоса .05, медленный дрейф 9s;
- рассеянный halo — radial-градиент к верхней кромке.

Клавиша `f` — тумблер эффекта (сравнить до/после).

### Прочее
- Воркспейс-переключение: бар вспыхивает и гаснет через 2.8s.
- Kill процесса: строка fade-out 400ms → удаление.
- DND: список приглушается, состояние в подвале.

## 6. Поведение превью (только для макета)

- Старт — пустой стол + пульт слева; клик по кнопке вызывает компонент на место.
- Пульт прячется за язычок `›`, когда что-то открыто; `esc` — чистый стол; `show all` — все каскадом (80мс шаг).
- Горячие клавиши без super: `r d a s t c n l` + `⇧s ⇧n ⇧a`, `1–6` воркспейсы, `h` — спрятать пульт, `f` — стекло.
- Хэши: `#static` — всё статично сразу; `#only=docker,chat` — только выбранные.
- Буквы в полях ввода не перехватываются.

## 7. Перенос в Quickshell — маппинг

| Макет (HTML/CSS) | Quickshell (QML) |
|---|---|
| `.panel` absolute на сцене | `PanelWindow` (WlrLayershell) на `overlay`/`top` layer;anchors из таблицы координат |
| `transition + cubic-bezier(.25,.1,.25,1)` | `Behavior on opacity/scale { NumberAnimation { easing: Easing.BezierCurve; easing.bezierCurve: [.25,.1,.25,1,1,1] } }` |
| контент после открытия (таймер) | `Timer { interval: 430 }` → `contentOpacity: 1`, внутри `SequentialAnimation` |
| ghost-эхо | 2 `Rectangle` c `border` + `Behavior on opacity/scale`, триггер = открытие |
| стекло-отражение (клон) | **`ShaderEffectSource`** панели → `ShaderEffect` (flip по Y, blur, opacity-градиент) — живое отражение |
| каретка `_` | `TextInput.cursorDelegate: Rectangle { width:8; height:2 }` + `Timer` blink 1070ms + пауза при вводе 900ms |
| сегментированная полоса | `Row { Repeater { Rectangle { width:4 } … } }` от величины значения |
| точка состояния | `Rectangle 7×7 radius:3.5`: цвет / ghost / `border` |
| транзиент бар | `Timer 2800ms`, рестарт на enter/leave, `Hyprland.dispatch("workspace")` на 1–6 |
| лаунчер 2 стадии | `states: ["dock","list"]` + `transitions`; фильтр — модель |
| хоткеи super+… | Hyprland binds → `bind = SUPER, R, exec, qs -p ...` или `GlobalShortcut` |
| обои | `Hyprland` wallpaper (путь к оригиналу см. ниже) |
| часы DSEG7 | ttf из пакета `dseg` рядом с конфигом, `FontLoader` |
| `#static / #only` | dev-флаги конфига (env `QS_LAYOUT=static`) |

Порядок переноса: **токены → панель-кит (head/body/foot) → примитивы (row/btn/chip/bar/dot) → один компонент (calendar — самый простой) → движение → остальные**.
