# ТЗ для дизайнера: ARCH·UI (quickshell shell «archui»)

Дата: 2026-11-05. Рабочий контекст: юзер только что вырезал панели docker/taskmgr; интерфейс
минималистичный, монохромный, тёмный. Задача дизайнера — предложить НОВЫЙ визуальный дизайн
этого же набора компонентов (новая эстетика при сохранении состава/логики), отрисованный как
HTML-страница-презентация: макет экрана ноута 1600×900 со всеми элементами «в кадре».

## Состав интерфейса (после чистки)

### Общая сетка
- Экран 1600×900 (retina-ноут, scale 1.2 → px-множитель ≈1.04 шрифтов/высот).
- Базовый отступ от краёв экрана **24**.
- Три «слота» — оконных колонки **504×544** каждая, прижаты к низу экрана:
  - слот A (лево, x≈24), слот B (центр), слот C (право, x≈1072). Один слот = одна панель.
- Панели открываются/закрываются по биндам, живут по одному на слот, поверх тайлов.
- Хореография: панель выезжает волной снизу (open 180ms, bezier «apple»), на замену —
  старая уходит за 120ms, ghost-контур из пустого слота.

### Слот A — SYSINFO (бинд SUPER+Z)
- Head (h40): иконка gauge + подпись «SYSINFO». Справа чип «up 5d 3:22» (uptime).
- Body: радиальные/строчные датчики, каждый ряд h28:
  - CPU: значение % + caption-подпись модели; мини-бар; живая sparkline-история
    (столбики; столбики ≥60% подсвечиваются).
  - MEM: «7.2/16.0 GB», caption «X available», бар.
  - GPU: значение % / iGPU; caption: модель + температура «76°». VRAM-ряд.
  - Строки hw: метка-колонка (ширина 84): «BAT», «NET», «DISK» и т.п. слева caps-меткой,
    значение по центру, мини-инфо справа (battery % + charge, сети eth/wifi, диск).
- Foot (h30): слева `USER@hostname`, справа `kernel 6.x-zen`.

### Слот B — LAUNCHER (SUPER+R) и LOGOUT (SUPER+L)
- Launcher — оверлей-«стекло» к нижней кромке слота:
  - Стадия 1: только dock-строка поиска h48 (поле ввода крупное, по центру).
  - Стадия 2 (первый символ): над доком вырастают 4 строки списка (каждая h34):
    плитка-инициал 24×24, имя приложения, справа dim-категория; выбранная строка инвертирована.
- Logout — панель h≈322: head «LOGOUT», 2 ряда плиток 64-высоты по центру
  (иконка + caps-подпись): LOCK / SLEEP / EXIT; REBOOT / POWER. Foot: `USER · up 5d 3:22`.

### Слот C — NOTIFICATIONS (SUPER+N)
- Head: иконка bell + «NOTIFICATIONS»; справа: dim-подпись «dnd», тумблер 32×18
  (бегунок 14×14, 160ms), кнопка «CLEAR» h26.
- Body: список уведомлений — источник caps, текст, время dim; счётчик непрочитанных.
- Foot: справа «5 unread · dnd off».

### Calendar отдельным окном (SUPER+C)
- Слева-сверху (x=24,y=24). Раскрыт: 264×288. Свёртывается в чип 264×40.
- Содержимое: дата и сетка месяца. ЧАСЫ В КАЛЕНДАРЕ УБРАНЫ (ред. 2026-11-05: юзер
  подтвердил — время живёт только в статус-баре, календарь чисто календарный);
  сегментный индикатор времени в дизайне НЕ отрисовывать.

### Status bar (SUPER+X, автоскрытие ~2.8s после ухода мыши) — ЛОГИКУ ПЕРЕСМОТРЕТЬ
- Юзер просит переосмыслить: расположение на экране, состав показываемой информации,
  и способ показа. Текущий вид (top-center 360×44, часы/воркспейсы/раскладка) —
  лишь стартовая точка; дизайнер волен предложить другое место (верх/низ/угол/
  кромка), другой набор данных и другой формат.
- Воркспейсы: НЕ сегмент-индикатор всех N. Нужна абстрактная индикация ИМЕННО
  ТЕКУЩЕГО воркспейса — просто его номер, без списка соседних.
- ОСД-режим (по кнопкам громкости/яркости): 240-сегментная шкала («полупиг»), %,
  иконка режима; кросс-fade 130ms с обычным баром; двойной триггер — пульс.
  Место ОСД и его связь с баром тоже предлагается пересмотреть в новом дизайне.

### Toasts
- Top-right (x=1324,y=24), стек шириной 276, растут вниз; автоскрытие.
- Тело: заголовок caps, текст, прилипший timer dim; выход — свайп/фейд.
- Мелкий глитч-флик на появлении (200ms) — фирменный приём.

## Текущая дизайн-система (то, от чего отталкиваться)
- **Цвета:** фон #000000 (всё на чёрном); текст #f4f4f5; вторичный #a1a1aa;
  dim #56565e; ghost-контуры #3f3f46; ховеры rgba(255,255,255,.05)/.09;
  акцентов НЕТ — единственный «акцент» это инверсия #f4f4f5 фон + #000000 текст.
- **Шрифт:** JetBrainsMono NFM везде (400–700); всё caps-подписи с letterspacing 1–2;
  для цифр-часов — сегментный DSEG7 Classic Bold.
- Иконки: тонкий stroke по 24-сетке (lucide-стиль), эффективная толщина 1.5, без заливки.
- Радиусы маленькие, 2–4px; границы вместо теней, теней нет вообще.
- Моушн: bezier «apple», длительности 120–350ms; панели — снизу волной, чипы/тумблеры
  — микро-переходы 120–160ms.
- Вайб: терминальный брутализм из 70s sci-fi: сегментные часы, глитч, ghost-контуры,
  ноль украшательств. Эстетика «изолятора в серверной без света» без эмo-неона.

## Цель редизайна
- Сохранить весь состав, смысл каждого элемента и монохромность (чисто ч/б + альфы).
- Предложить НОВУЕ визуальное прочтение: типографика, ритм, плотность, формы,
  дополнительные micro-details (метки-координаты, сетка, сканлайны?) — на выбор дизайнера.
- Отдать как один самодостаточный HTML (без внешних CDN), экран 1600×900 и рядом лупа на
  состояния (открытие панели, hover, dnd on, ОСД тумбл, тост с глитчем). Таймлайн-моушн не
  обязателен, статику с hover-состояниями достаточно.
- Все подписи контента — те же, что выше; можно добавить атмосферные системные подписи
  (координаты, версии, PROJECT NAME), не меняя функциональных.
