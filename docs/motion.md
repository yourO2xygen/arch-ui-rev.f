# Motion: движение в одном месте

Motion.qml — единственное место движения: ни один компонент не хардкодит
длительности и кривые. Менять тайминги — только здесь.

## Принцип

**Motion — единственное место движения.** Новая анимация = новый токен в
Motion.qml + использование в компоненте. Кривая всегда `apple`, если нет
явной причины иначе.

Каноническое использование (последние две единицы — контрольная точка 1,1,
требование Qt для BezierSpline):

```qml
NumberAnimation {
    duration: Motion.panelOpen
    easing.type: Easing.Bezier
    easing.bezierCurve: Motion.apple
}
```

## Кривая apple

`[0.25, 0.1, 0.25, 1, 1, 1]` — базовая кривая всех переходов (Bezier .25,.1,.25,1).

## Токены

### Панель (kit/Panel.qml)

| Токен | мс | Семантика |
|---|---|---|
| `panelOpen` | 420 | открытие: opacity 0→1 + scale .97→1 |
| `contentDelay` | 430 | контент снимается с паузы на этой мс |
| `contentFade` | 220 | fade контента |
| `ghostDelay1/2` | 40/140 | задержки двух ghost-контуров |
| `ghostFade` | 620 | длительность ghost-эха (scale .99→.952, opacity .45→0); **на replace отключено** |
| `replaceExit` | 180 | замена: старая уходит (fade + scale .97, без ghost) |
| `replaceStagger` | 120 | новая стартует на +120ms выше по z |

| `glitchLite` | 200 | дешёвый глич: тосты/бар (flicker + x-джиттер + 2 инверсные полосы) |

## Глич: семантика

Глич — **только открытие** (панели, тосты, бар). Никакого глича на
закрытии/замене/ховерах. Панели — полный ShaderEffect (построчный x-сдвиг
срезов, моно-двоение двумя alpha-копиями — не RGB, инверсные полосы, flicker,
скан-линия) над `layer.enabled` волны, live только `glitchPanel` мс, потом
`live=false` — постоянной GPU-цены ноль. `Theme.glitch=false` — lite-вариант
везде и текстуры не создаются.

Lite-вариант (тосты/бар) анимирует **только не-бинженые** свойства (x карточки
тостов задан императивно, бару — отдельный transform: Translate).

Джиттерим Item внутри поверхности, не окно.

Монохромность структурно гарантирована шейдером (`vec3(l*fl)`), не фильтром.

## Отладка анимаций

Скриншотить 350ms-переход нельзя (grim ~460ms/кадр): временно поставь
`glitchPanel: 4000`, сними серию, верни токен. Стоимость кадра —
`QSG_RENDER_TIMING=1 QT_LOGGING_RULES="qt.scenegraph*.debug=true"` в qslog
by-id.
